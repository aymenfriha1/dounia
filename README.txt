PROJECT 1609 🌹
================

ملفات الموقع:
- index.html: الموقع كاملاً في ملف واحد.

التجربة:
1) افتح index.html على الهاتف أو الحاسوب للتجربة.
2) رمز الدخول هو 1609.
3) المرحلة الثانية تحتوي الأسئلة والأجوبة كما زودتني بها:
   jam3 mngouli? -> mnagl
   chek? -> agherdha
   afdal makla 3ndi? -> ana
4) المرحلة الثالثة: زر "لا" يهرب، وزر "نعم" يفتح النهاية.
5) النهاية: وردة سحرية مضيئة متعددة الألوان وعبارة "هكذا أراكِ".

الأصوات:
- اضغط زر الصوت أعلى الصفحة لتفعيل مؤثرات الاختيار والنجاح والخطأ.
- المتصفح قد يمنع الصوت قبل أول لمسة من المستخدم.
- موسيقى النهاية لحن إلكتروني بسيط مولّد داخل المتصفح، وليست أغنية مسجلة.

التعديل:
افتح index.html بمحرر نصوص مثل Notepad أو VS Code.
يمكن تعديل الأسئلة والأجوبة داخل مصفوفة answers في JavaScript.

النشر:
يمكن رفع index.html إلى مستودع GitHub ثم تفعيل GitHub Pages من:
Settings > Pages > Deploy from a branch > main > /(root) > Save.

تنبيه:
رمز الدخول موجود في كود الصفحة، لذلك هو بوابة لعبة ومفاجأة وليس حماية أمنية حقيقية.
الخط Cairo يُحمّل من Google Fonts عند توفر الإنترنت، مع خط بديل عند عدم توفره.
